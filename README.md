# AI-Driven Customer Churn & Insights Analytics

An interactive AI application built with **Python**, **Scikit-Learn**, and **Streamlit** using **IBM Bob IDE**.

## 🚀 Features
- **Data Overview:** View customer dataset stats and structure.
- **Real-Time Prediction:** Predict individual customer churn probability based on tenure, spend, and support interactions.
- **Business Insights:** Feature importance chart identifying primary churn drivers.
